# account

Per-account lifecycle skills. Run once per account to establish or refresh context - briefs, project setup, onboarding.

## Skills in this category

| Skill | Description |
|---|---|
| [account-brief](account-brief/SKILL.md) | Build or refresh the Account Brief for a MAX customer — pulls live data, interviews the analyst, and produces the brief doc, index row, and project-instructions block. |
| [project-setup](project-setup/SKILL.md) | One-time setup that builds a project manifest for a new MAX customer project from live sources plus analyst input. |

See [GOVERNANCE.md](../../GOVERNANCE.md) for category definitions.
