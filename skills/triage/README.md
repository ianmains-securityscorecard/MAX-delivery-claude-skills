# triage

MAX workstation triage skills. Breach, hostname, and findings triage against the MAX Partner API.

## Skills in this category

| Skill | Description |
|---|---|
| [max-breach-triage](max-breach-triage/SKILL.md) | Triages untriaged MAX workstation breaches using SOP-backed decision rules — classifies REPORT vs HIDE, surfaces ambiguous items, and writes the triage on confirmation. |
| [max-findings-triage](max-findings-triage/SKILL.md) | Bulk-triages MAX partner findings and breaches (report/triaged flags) via the MAX partner API. |
| [max-hostname-triage](max-hostname-triage/SKILL.md) | Two-phase triage that checks whether hostname findings belong to the flagged vendor domain before bulk-clearing the rest, preventing mis-attributed reports. |

See [GOVERNANCE.md](../../GOVERNANCE.md) for category definitions.
